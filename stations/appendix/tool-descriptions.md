# Tool descriptions

{% hint style="info" %}
Filter the table below based on the specifications of your station.&#x20;

**Station Configuration**

Select all that apply. For example, if selecting Rock-Anchored, select an additional attachment method (e.g., Building-Bracketed or Guy-Wired) to generate a complete list of recommended tools.&#x20;

**Power Source**

The source used to power the receiver at the station.&#x20;

**Receiver Type**

The computer installed at the station. Options are a Cellular Tracking Technology SensorStation or a SensorGnome (i.e., a Raspberry Pi).&#x20;

**Station Activity**

Indicates whether the station is being installed for the first time or whether tools are being brought for inspection or maintenance of an existing station. The tools listed for maintenance are a minimum recommended sets. However, all installation tools are recommended for each visit to ensure you are prepared for unexpected needs or adjustments.
